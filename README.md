Ответы на вопросы:

1. Чем статическая типизация Dart отличается от Python? Какое практическое преимущество она даёт?
   В Dart типы данных проверяются на этапе компиляции, а не во время выполнения программы (как в динамическом Python). Преимущество в том, что ошибки в типах обнаруживаются сразу в редакторе кода до его запуска, что повышает надежность крупных проектов.
2. Что означает String?? Чем отличается от String?
   String? означает, что переменная может хранить либо строку, либо значение null. Обычный String не может быть null — попытка присвоить ему пустоту вызовет ошибку.
3. Зачем в Dart final, если в Python можно просто договориться не менять переменную?  
   Ключевое слово final защищает данные на уровне компилятора — программа физически не позволит случайно перезаписать эту переменную. В командной разработке или больших приложениях надежность важнее договоренностей.
4. Чем именованный параметр {required String name} отличается от позиционного? Приведите пример вызова.
   Позиционные параметры передаются строго по порядку их объявления в функции. Именованные параметры передаются по имени (через двоеточие), порядок при вызове не важен, а required делает такой параметр обязательным для заполнения.  
   Пример вызова: describePet(name: 'Барсик', age: 3);`[cite: 15]
